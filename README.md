# Aurus Syndicus

A Dutch-language website for an apartment property manager. Visitors can explore technical, administrative and financial management services, browse the FAQ and contact the team through EmailJS forms.

Run `npm ci` and `npm run dev` to start the React and Vite app. See [.env.example](.env.example) for the form settings. Use `npm run build` to produce the static site in `dist/`.
